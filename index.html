Making a purchase order

  1. Fill in the order number, date and supplier.
  2. Add each truck with litres and price. Totals are calculated for you.
  3. Tap Preview, then Print / Save PDF. The order is saved at the same time.

Orders stay on this phone only. Save a backup file regularly from the Saved tab.

Backup

A backup file contains every saved order, the company details, the logo and the signature. Save one at least once a week and after important orders, and keep it somewhere safe (Files, Google Drive, email). To move to a new phone, restore the backup file there.

Storage on this device

    Orders stay in this browser on this device. They are not copied to other phones, computers or browsers. Clearing Safari's history or website data deletes them, and Safari can also remove them if the app is not opened for several weeks. Backup files protect you against this.

    Using this app on iPhone

    • Open the app from its https:// link in Safari. A file preview inside WhatsApp, Mail or Files may not run the app.
    • Always use the same link: orders are stored for that address only.
    • For quick access, tap Share → Add to Home Screen.
    • To make a PDF: open Preview, tap Print / Save PDF, then use the Share button in Print Options.
